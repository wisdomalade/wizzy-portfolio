# Wizzy Portfolio

A responsive backend developer portfolio built with HTML, CSS, and JavaScript.

## Project files

- `index.html` — portfolio content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and dynamic footer year
- `assets/Ghost_Student_Selected_Postman_Evidence.pdf` — Postman testing evidence for the Ghost Student API project

## Run locally

Open `index.html` in your browser, or use the VS Code Live Server extension.

## GitHub Pages deployment

The portfolio is published through GitHub Pages. After making changes, test the navigation, project links, mobile layout, and PDF link before committing and pushing.

## API testing evidence

The included PDF documents Postman testing evidence. It does not mean the API itself is publicly hosted; the evidence was captured from a local test server.
